# FitRight AI — MVP 产品设计方案

## 一、产品概述

### 1.1 产品定位
FitRight AI 是一款基于人工智能的智能健身助手应用，帮助用户进行运动动作纠错、体态评估、以及个性化健身计划定制。

### 1.2 目标用户
- 健身新手：不确定动作是否标准，担心受伤
- 有体态问题的用户：圆肩、驼背、骨盆前倾等
- 想要定制计划的用户：需要根据自身条件获取专业训练方案

### 1.3 核心价值主张
> "上传训练视频，获取专业指导" — 让每个人都能拥有 AI 私人教练

## 二、MVP 功能范围

### 2.1 功能优先级矩阵

| 功能模块 | MVP 阶段 | 优先级 | 说明 |
|---------|---------|--------|------|
| AI 运动纠错 | ✅ | P0 | 核心功能，上传视频 → AI 分析 → 给出建议 |
| 体态评估 | ✅ | P0 | 核心功能，上传照片 → AI 评估 → 改善建议 |
| AI 对话（健身顾问） | ✅ | P0 | 核心功能，对话式定制健身计划 |
| 个人中心 | ✅ | P1 | 基础信息展示、训练记录 |
| 用户注册/登录 | ✅ | P0 | 手机号/微信登录 |
| 训练进度追踪 | ✅ | P1 | 本周训练进度、累计数据 |
| Pro 会员系统 | ❌ | P2 | 后续版本 |
| 成就与徽章 | ❌ | P2 | 后续版本 |
| 社区功能 | ❌ | P3 | 后续版本 |

### 2.2 MVP 核心排除项
- 实时摄像头动作检测（MVP 仅支持视频上传后分析）
- 会员付费系统
- 社交/社区功能
- 多语言支持

## 四、页面详细设计

### 4.1 首页（AI纠错 Tab）

**页面结构：**
- 顶部：蓝色渐变头部，品牌名 "FitRight AI"，副标题 "上传训练视频，获取专业指导"
- 内容区：两张功能卡片
  - **运动纠错卡片**：图标 + 标题 "运动纠错" + 描述 "分析健身动作，纠正错误姿势" + 标签（深蹲/卧推/硬拉）
  - **体态评估卡片**：图标 + 标题 "体态评估" + 描述 "评估身体姿态，改善体态问题" + 标签（圆肩/驼背/骨盆前倾）
- 底部：Tab 导航栏（AI纠错 / AI对话 / 我的）

**交互逻辑：**
- 点击运动纠错卡片 → 跳转到运动纠错页
- 点击体态评估卡片 → 跳转到体态评估页

---

### 4.2 运动纠错页

**页面结构：**
- 顶部：蓝色头部 + 返回箭头 + 标题
- 中心区域：上传区域
  - 运动图标
  - 文字 "上传运动视频"
  - 副文字 "支持深蹲、卧推、硬拉等多种动作分析"
  - 蓝色按钮 "选择视频"
- 下方：支持的动作类型标签（深蹲/卧推/硬拉/引体向上/俯卧撑/弓步蹲）

**交互流程：**
1. 用户点击 "选择视频" → 系统相册选择视频（限制60s内，100MB以内）
2. 选择动作类型（可选，AI 也会自动识别）
3. 点击 "开始分析" → 视频上传 → 显示分析进度
4. 分析完成 → 跳转结果页

**分析结果页内容：**
- 动作整体评分（0-100分）
- 关键帧截图 + 问题标注
- 存在的问题列表（每个问题含：问题描述、危害说明、改进建议）
- 总结性指导建议

---

### 4.3 体态评估页

**页面结构：**
- 顶部：标题 "体态评估"
- 上传区域：三个图片上传框（正面/侧面/背面）
- 提示文字：拍摄注意事项
- 按钮 "开始评估"

**交互流程：**
1. 用户分别上传正面、侧面、背面照片（或视频截帧）
2. 点击 "开始评估" → 上传 → AI分析
3. 分析完成 → 显示评估结果

**评估结果页内容：**
- 体态总评（正常/轻度异常/中度异常/重度异常）
- 检测到的问题列表：
  - 问题名称（如：圆肩）
  - 严重程度（轻度/中度/重度）
  - 问题成因分析
  - 可能引发的健康问题
- 改善训练方案：
  - 针对性训练动作列表
  - 每个动作的组数/次数/要领
  - 训练频率建议

---

### 4.4 AI 对话页

**页面结构：**
- 顶部：紫色渐变头部，标题 "AI 健身顾问"，副标题 "智能定制你的训练计划"
- 快速开始区域：
  - 增肌训练计划（带图标）
  - 减脂方案
  - 每周训练安排
- AI 助手消息气泡："你好！我是 FitRight AI 健身助手。我可以帮你定制专属训练计划，解答健身问题。请告诉我你的健身目标？"
- 底部：输入框 "输入你的健身问题..." + 发送按钮

**首次使用信息采集弹窗：**
- 触发条件：用户首次进入AI对话页 或 点击快速开始卡片
- 弹窗内容（分步骤）：
  - Step 1：基本信息（性别/年龄/身高/体重）
  - Step 2：训练目标（增肌/减脂/塑形/体能提升/康复训练）
  - Step 3：训练经验（新手/初级/中级/高级）
  - Step 4：训练偏好（健身房/徒手/家庭器械）
  - Step 5：单次训练时长（30min/45min/60min/90min）
  - Step 6：重点训练部位（多选：胸/背/腿/肩/手臂/核心/全身）
- 采集完成后，信息作为上下文注入AI对话

**对话交互：**
- 支持流式输出（逐字显示）
- AI 回复支持富文本格式（标题/列表/加粗）
- 点击快速开始卡片直接发送对应消息
- 历史对话记录保存

---

### 4.5 我的页面

**页面结构：**
- 顶部：紫色/橙色渐变背景
  - 设置图标（右上角）
  - 用户头像（圆形）
  - 昵称 "健身达人"
  - 签名 "坚持就是胜利 👍"
- 数据统计栏（三列）：
  - 累计训练（天）
  - 本周完成（次）
  - 总时长（小时）
- 升级 Pro 会员入口（金色渐变卡片）
- 本周训练进度：
  - 周一到周日的圆形指示器（绿色=已完成，灰色=未完成）
  - 完成率百分比 + 进度条
- 功能列表：
  - 我的训练计划
  - 成就与徽章

## 六、用户旅程（核心场景）

### 场景一：运动纠错
```
用户打开App → 首页看到"运动纠错"卡片 → 点击进入 → 选择视频 → 
选择动作类型 → 上传分析 → 等待AI处理(约15-30秒) → 
查看分析结果(评分/问题/建议) → 可保存或分享
```

### 场景二：体态评估
```
用户点击"体态评估"卡片 → 分别上传正面/侧面/背面照片 → 
开始评估 → 等待AI处理(约10-20秒) → 
查看评估结果(问题识别/严重程度/改善方案)
```

### 场景三：AI对话定制计划
```
用户切换到"AI对话"Tab → 首次弹出信息采集弹窗 → 
填写个人信息(6步) → 提交后AI自动生成问候 → 
用户输入健身问题或点击快速开始 → AI流式回复 → 
生成训练计划 → 保存到"我的训练计划"
```

## 七、UI/UX 设计规范

### 7.1 色彩体系
| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 首页/纠错主色 | #4A90D9 → #2B6CB0 | 蓝色渐变，专业信赖 |
| AI对话主色 | #8B5CF6 → #6D28D9 | 紫色渐变，智能科技 |

| 成功/完成 | #10B981 | 绿色 |
| 警告/问题 | #EF4444 | 红色 |
| 背景色 | #F5F5F5 | 浅灰 |
| 卡片背景 | #FFFFFF | 白色 |

### 7.2 字体规范
- 标题：18-24px，Bold
- 正文：14-16px，Regular
- 辅助文字：12px，Regular，#999999

### 7.3 圆角规范
- 卡片：12-16px
- 按钮：24px（全圆角）
- 头像：圆形
- 标签：16px

### 7.4 底部导航栏
- 三个Tab：AI纠错（摄像机图标）/ AI对话（对话图标）/ 我的（人形图标）
- 选中态：主题色 + 加粗
- 未选中：灰色 #999999

## 八、MVP 验证指标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 运动纠错完成率 | > 80% | 用户上传视频后成功获取分析结果 |
| 体态评估完成率 | > 80% | 用户上传照片后成功获取评估结果 |
